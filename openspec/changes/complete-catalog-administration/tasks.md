# Complete catalog administration implementation tasks

## Scope and delivery rules

Implement the approved design additively under `convex/catalogoAdmin/`, preserving every existing export in `convex/catalogoRecursos/`. Keep each behavior slice independently reviewable: its tests stay with its behavior, each slice has a bounded rollback, and no slice introduces hard deletion, authentication, seed data, UI validation, or automatic publication.

Strict TDD is mandatory even though the current `openspec/config.yaml` is stale. For every behavior slice, execute **RED → GREEN → TRIANGULATE → REFACTOR** in that order. RED must demonstrate a focused failure, GREEN must provide the smallest passing implementation, TRIANGULATE must exercise adjacent failure paths and full regression/type checks, and REFACTOR must preserve the passing evidence. Runtime verification uses `pnpm exec convex dev --once` when a deployment is available; otherwise record `N/A — no deployment available`, never a fabricated success.

Generated `convex/_generated/*` output is **derived**: do not hand-edit it and exclude it from authored-line estimates, but include it in codegen, typecheck, diff, and contract verification.
